# Keyboard shortcuts

| Action | Shortcut |
|---|---|
| New document | Command-N |
| Open | Command-O |
| Close window | Command-W |
| Save | Command-S |
| Save As | Shift-Command-S |
| Settings | Command-, |
| Undo / Redo | Command-Z / Shift-Command-Z |
| Cut / Copy / Paste | Command-X / Command-C / Command-V |
| Select All | Command-A |
| Find | Command-F |
| Find and Replace | Option-Command-F |
| Find Next / Previous | Command-G / Shift-Command-G |
| Indent / Outdent selection | Command-] / Command-[ |
| Go to Line | Control-Command-L |
| Toggle Markdown preview | Shift-Command-P |
| Increase / decrease editor font | Command-+ or Command-= / Command-- |
| Reset editor font size | Command-0 |
| Enter Full Screen | Control-Command-F |
| Hide / Quit | Command-H / Command-Q |

All core editing, navigation, preview, save, and window actions are available
without a pointing device through the menu bar and macOS responder chain.
Markdown preview is unavailable above the measured 5 MiB safety ceiling.
